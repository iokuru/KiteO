Problemset
A. Watermelon
time limit per test
1 second
memory limit per test
64 megabytes

The first (and the only) input line contains integer number w (1 ≤ w ≤ 100).

#include <iostream>
using namespace std;
int main() {
int w; cin >> w;
if (w > 2 && w % 2 == 0) cout << "YES\n";
else cout << "NO\n";
return 0;
}
